# Кручёный удар

Аркадный настольный теннис вид сверху для Яндекс Игр. HTML5, чистый JavaScript и Canvas 2D:
без фреймворков, сборщиков и внешних ассетов — вся графика и звук генерируются кодом.

Название игры зафиксировано одной строкой — **Кручёный удар**. Ровно она должна стоять
в `<title>`, на стартовом экране, в поле «Название» черновика, на иконке и на обложке
(требование 5.1.3, замечание модерации по прошлой игре).

## Запуск

Игра собрана из ES-модулей, поэтому нужен любой статический сервер — по `file://`
модули не загрузятся.

```
npx http-server -p 8080 .
# затем открыть http://127.0.0.1:8080/index.html
```

Отладочный режим: `index.html?debug` — кладёт состояние игры в `window.__game`.

Сборка в один файл (нужна только для превью по ссылке, на Яндекс Игры загружаются
обычные файлы репозитория):

```
node tools/bundle.mjs            # dist/krucheny-udar.html
node tools/bundle.mjs --no-sdk   # то же без внешнего скрипта SDK
```

Онлайн-проверка через GitHub Pages: Settings → Pages → Source: Deploy from a branch →
ветка `main`, папка `/ (root)`. Игра откроется по адресу
`https://fleuki.github.io/PingPong_Game/`.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | разметка канваса и экранов интерфейса |
| `styles.css` | оболочка, экраны, запрет выделения и контекстного меню |
| `src/config.js` | **весь баланс и геометрия в одном месте** |
| `src/game.js` | состояние матча, физика мяча, удары, счёт |
| `src/ai.js` | соперник: предсказание траектории, реакция, ошибка |
| `src/render.js` | отрисовка стола, ракеток, мяча, следа, счёта |
| `src/effects.js` | частицы удара и вспышка счёта |
| `src/input.js` | палец, мышь, клавиатура |
| `src/ui.js` | экраны меню, паузы и конца матча |
| `src/audio.js` | звук на осцилляторах Web Audio |
| `src/sdk.js` | Yandex Games SDK: язык, GRA, реклама, сохранения |
| `src/storage.js` | прогресс: облако + `localStorage` |
| `src/main.js` | точка входа и игровой цикл |
| `promo/promo.html` | служебная страница: рисует иконку 512×512 и обложку 800×470 |
| `tools/bundle.mjs` | сборка всей игры в один HTML-файл (для превью по ссылке) |

## Физика

- Логическое поле 600×1000, канвас вписывается по `min(scaleX, scaleY)` — contain.
- Физика с фиксированным шагом 1/120 с, `dt` сверху ограничен 1/30 с.
- Столкновение мяча с ракеткой — swept collision по отрезку движения в системе отсчёта
  ракетки, поэтому на максимальной скорости (1400 ед/с) мяч не проходит сквозь ракетку.
- Удар зависит от точки попадания по ракетке, скорости ракетки навстречу мячу и её
  бокового движения (подкрутка). Подкрутка искривляет траекторию и затухает.
- Каждый удар ускоряет розыгрыш на 2 % до потолка; новый розыгрыш начинается с базовой скорости.

Баланс правится только в `src/config.js`.

## Соответствие требованиям Яндекс Игр

Сделано в коде:

- **§ 1.1 / § 1.19.2** — SDK подключён с `https://yandex.ru/games/sdk/v2`,
  `LoadingAPI.ready()` вызывается после загрузки, `GameplayAPI.start()/stop()` — на старте
  матча, паузе, возврате в меню, конце матча и на время рекламы.
- **§ 2.14** — язык берётся из `ysdk.environment.i18n.lang`; поддержан только русский,
  любой другой язык откатывается на него (`src/i18n.js`).
- **§ 1.6** — отключены выделение, перетаскивание, контекстное меню и жест масштабирования.
- **§ 1.10** — contain-масштабирование, интерфейс прижат к безопасной области;
  проверено на 320×568, 360×800, 412×915, 768×1024, 1440×800 и в альбомной ориентации —
  страница нигде не прокручивается и ничего не обрезается.
- **§ 1.3 / § 4.7** — звук паузится по `visibilitychange` и `blur`, а также на время рекламы;
  вместе со звуком встаёт на паузу и геймплей.
- **§ 1.9** — сложность, звук, лучшая серия ударов и число побед сохраняются через
  `player.setData()` с фоллбэком на `localStorage`.
- **§ 4.4** — межстраничная реклама только между матчами, не чаще одного раза в 185 секунд.
- **§ 4.5** — rewarded только по нажатию кнопки «Смотреть рекламу и переиграть очко»
  на экране поражения.
- **§ 3.5 / § 3.6** — внешних ассетов нет вообще: графика и звук генерируются кодом.

Остаётся сделать вручную перед отправкой на модерацию:

1. Проверить уникальность названия «Кручёный удар» по каталогу Яндекс Игр (§ 5.12).
2. Открыть `promo/promo.html`, сохранить иконку 512×512 и обложку 800×470.
3. Снять скриншоты (десктопные и мобильные, портретная ориентация) — только на русском.
4. Заполнить черновик: платформы, ориентация «Портретная», язык — **только Русский**,
   возрастной рейтинг, категории, описания.
5. Запустить игру в режиме черновика и проверить консоль браузера (§ 1.14).
6. Пройти чеклист из 23 пунктов и отметить использование ИИ.
